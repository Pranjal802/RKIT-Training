referrerpolicy=""
  • no-referrer : It disabled the transfer of the confidential data when you clicked any external link in web page.
  • no-referrer-when-downgrade : It allows required data if and only if when the external link is secured(https) and it will not allow in non secured urls(http).
  • origin : It allows only origin to send to the external url.
target=""
  • _blank : It opens the url in new tab.
  • _self : Opens url in same tab.
  • _parent : If we are using iframe and the external link is given in iframe, when user clicks url will open in that parent tab and iframe will be disappeared. If no parent it will work like _self.
  • _top : if there are nested iframes than it will open in top parent tab and all iframes will be disappeared.
